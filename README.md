# CodeMl2026-EquiAlgo

Solution du défi IVADO EquiAlgo sur l’apprentissage automatique.

## Objectif

Documenter les expériences, la validation sans fuite de données, les métriques et la procédure de reproduction des résultats.

## Organisation du dépôt

Le dépôt est un point de départ. Le code, les instructions de reproduction et les décisions de conception seront ajoutés après revue des fichiers de travail et des règles du défi.

## Données et confidentialité

Ne pas committer les données du défi, labels cachés, prédictions de soumission privées, credentials ou secrets. Les règles officielles du défi déterminent ce qui peut être partagé. Ajouter uniquement des données explicitement autorisées; privilégier des exemples synthétiques et des scripts qui téléchargent les données depuis leur emplacement approuvé.

## Reproduction

À compléter lorsque l’environnement et les commandes de lancement auront été vérifiés.
